# Harmless offline research fixture

valid-demo.json is labelled controlled demo data. Its reserved .example URLs are deliberately not factual sources or live endpoints. The validator checks their syntax only and never requests them.

Use valid-demo.json to reproduce PASS and invalid-demo.json to reproduce FAIL (deliberately too few sources). The tests also remove records/change required fields/duplicate URLs. These are local task-validation results, not payment, provider delivery, on-chain execution, or an owner attestation.

Do not replace fixtures with private research/prompts/credentials. Real artifacts belong in ignored local storage and require privacy review before any export/publication.
